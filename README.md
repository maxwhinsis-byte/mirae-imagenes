# mirae-imagenes

## Cinturones (recortes)

- `cinturones/colores/` — 22 cinturones por color (`_liso` y `_franja_negra`).
- `cinturones/tigers/completos/` — 9 cinturones Tigers (blanco a rojo).
- `cinturones/tigers/animal_y_linea_lisa/` — Tigers: animal + línea de color liso.
- `cinturones/tigers/animal_y_patron/` — Tigers: animal + línea con patrón.
- `cinturones/negros_dan/` — cinturones negros 1.º, 2.º y 3.º dan con cuadrado dorado y número romano (`tamano_original` y `tamano_grande`).

Todos son PNG con fondo transparente.
